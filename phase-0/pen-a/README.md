# Phase 0 — Pentest (แบบ A): Parser ผลสแกนช่องโหว่จาก Nmap

## ภาพรวม
สคริปต์สำหรับแปลงรายงานผลสแกนจาก Nmap รูปแบบ XML (`scan1.xml` และ `scan2.xml`) ให้เป็นโครงสร้าง JSON กลางของแพลตฟอร์ม โดยตรวจสอบขอบเขต IP เป้าหมาย (`scope`) คัดกรองเฉพาะพอร์ตที่เปิดอยู่ (`open`) เปรียบเทียบความเปลี่ยนแปลงระหว่างสองรอบสแกน (`diff`) ระบุบริการที่มีความเสี่ยงสูง (`risky`) และตรวจสอบความถูกต้องของข้อมูลด้วย Pydantic Schema

## โครงสร้างไฟล์
```text
phase-0/pen-a/
├── nmap_parse.py        # สคริปต์หลักสำหรับแกะ XML, เปรียบเทียบผลสแกน และตรวจความเสี่ยง
├── scope.json           # ขอบเขต IP / Subnet ที่ได้รับอนุญาตให้ประมวลผล
├── scan1.xml            # ไฟล์ผลสแกน Nmap รอบที่ 1
├── scan2.xml            # ไฟล์ผลสแกน Nmap รอบที่ 2
├── output.json          # ผลลัพธ์ JSON ที่ผ่านการตรวจสอบ Schema
└── README.md
```

## การติดตั้งและวิธีรันใช้งาน
```bash
# ติดตั้งไลบรารีที่จำเป็น
pip install pydantic

# รันสคริปต์เปรียบเทียบผลสแกนรอบที่ 1 และรอบที่ 2 แล้วบันทึกผลลัพธ์เป็น JSON
python nmap_parse.py scan1.xml scan2.xml > output.json
```

## หลักการทำงานและเงื่อนไขการประมวลผล
1. **การตรวจสอบขอบเขต (Scope Validation):** ตรวจสอบ IP เป้าหมายให้อยู่ในขอบเขตที่กำหนดไว้ในไฟล์ `scope` หากพบ IP นอกขอบเขตจะปฏิเสธการประมวลผลทันที
2. **การอ่านไฟล์ XML (`xml.etree.ElementTree`):** ดึงข้อมูลจากแท็ก `<host>` โดยเจาะจง `<address addrtype="ipv4">` และวนลูปพอร์ตภายใต้ `<ports>` โดยไม่ใช้ Regular Expression
3. **การคัดกรองพอร์ต (`findings`):** นับเฉพาะพอร์ตที่มีสถานะ `state == "open"` ใน `scan2.xml` เท่านั้น (ตัดพอร์ตสถานะ `closed` และ `filtered` ออก) พร้อมรวมชื่อผลิตภัณฑ์และเวอร์ชัน (`product` และ `version`)
4. **การเปรียบเทียบระหว่างรอบสแกน (`diff`):**
   - `opened`: รายการ `host:port` ที่เปิดใหม่ใน `scan2.xml` (ไม่มีใน `scan1.xml`)
   - `closed`: รายการ `host:port` ที่เคยเปิดใน `scan1.xml` แต่ปิดหรือถูกกรองไปแล้วใน `scan2.xml`
5. **การระบุบริการเสี่ยง (`risky`):** คัดกรองเฉพาะบริการที่เปิดอยู่ใน `scan2.xml` ได้แก่ `ftp`, `telnet`, `microsoft-ds` และ `ms-wbt-server`

```json
{
  "findings": [
    {
      "host": "10.10.10.5",
      "port": 21,
      "service": "ftp",
      "version": "vsftpd 3.0.5"
    },
    {
      "host": "10.10.10.5",
      "port": 22,
      "service": "ssh",
      "version": "OpenSSH 8.9p1"
    }
  ],
  "diff": {
    "opened": [
      "10.10.10.5:21"
    ],
    "closed": [
      "10.10.10.8:23"
    ]
  },
  "risky": [
    "10.10.10.5:21",
    "10.10.10.8:445",
    "10.10.10.8:3389"
  ]
}
```
